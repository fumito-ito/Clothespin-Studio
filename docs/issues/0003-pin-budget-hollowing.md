## 目的

実サイズ（例 40–80cm）のモデルを `PIN_LIMIT`（20000）以内に収める。
ソリッド充填はピン数が桁で爆発するため、中空化（シェル化）と解像度調整を導入する。

## 受入基準

- [ ] シェル化: 表面から N ボクセル厚のみ目標に残すオプション（内部は捨てる）
- [ ] シェル化後も成長で単一連結を保てる（薄殻での連結性を実測）
- [ ] ボクセル一辺（既定 45mm）を UI から調整可能
- [ ] 生成前にピン数見積もりを表示し、上限超過時は誘導（解像度/シェル厚の変更提案）
