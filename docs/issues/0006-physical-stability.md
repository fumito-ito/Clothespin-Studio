## 目的

生成された連結体が現実に組めて自立するかを評価する。
幾何的に正しくても、自重で倒れる/接合が保たない/組立順序が存在しない構造は成果物にならない。

## 受入基準

- [ ] 重心と接地範囲から転倒判定（静的安定性の一次評価）
- [ ] 片持ち長（根本からの張り出し）に基づく接合強度の警告
- [ ] 木構造から組立手順（ルート → 葉の順序）を出力できることの確認
- [ ] 不安定な生成結果に UI で警告を表示
